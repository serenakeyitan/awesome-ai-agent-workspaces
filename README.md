# Awesome AI Agent Workspaces

AI coworking / workspace products for **one-person companies** and **teams** — where AI agents are persistent teammates, not one-off tools.

**Subscription** = how you pay for the agents: 🟢 bring your own (your Claude/Codex plan) · ☁️ vendor cloud (hosted, they bill compute).

### [Paperclip](https://paperclip.ing) — Free · MIT
Run agents like a **company**: org chart, per-agent budgets, approval gates.

- **For:** solo founders & teams, all functions (not just code)
- **Agents:** Claude Code, Codex, Gemini, Cursor, +more
- **Subscription:** 🟢 bring your own (self-hosted)

### [First-Tree](https://first-tree.ai) — Free · Apache-2.0
A git-native shared **context layer** (team memory); auto-routes GitHub issues.

- **For:** engineering teams (1–100 agents)
- **Agents:** Claude Code, Codex
- **Subscription:** 🟢 bring your own (routes via cloud.first-tree.ai)

### [Multica](https://multica.ai) — Free · Apache-2.0
An **issue tracker** where agents are first-class assignees, plus reusable Skills.

- **For:** engineering teams
- **Agents:** Claude Code, Codex, Copilot, Gemini, Cursor, +more
- **Subscription:** 🟢 bring your own (cloud option = coordination only)

### [Slock](https://slock.ai) — Freemium
**Chat *is* the workspace** — servers, channels, DMs; agents have their own memory.

- **For:** solo builders & lean teams
- **Agents:** Claude Code, Codex
- **Subscription:** 🟢 bring your own (local daemon)

### [Hivespace](https://hivespace.app) — Closed
Each workspace is a **cloud computer** with a shared file system + agent-built artifacts.

- **For:** teams, general knowledge work
- **Agents:** Claude Code, Codex
- **Subscription:** ☁️ vendor cloud (login-gated)

### [Vibe Kanban](https://github.com/BloopAI/vibe-kanban) — Free · Apache-2.0 · *sunsetting*
A **kanban board**; each card runs an agent in an isolated git worktree.

- **For:** solo engineers or teams
- **Agents:** Claude Code, Codex, Gemini, Copilot, +more
- **Subscription:** 🟢 bring your own · ☁️ cloud tier (winding down)
