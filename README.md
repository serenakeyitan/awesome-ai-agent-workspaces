# Awesome AI Agent Workspaces

Tracking AI coworking / workspace products and frameworks for **one-person companies** and **teams** — where AI agents are persistent teammates in a shared workspace, not one-off tools.

Each entry: **who it's for** and its **unique value prop** (the one thing it does that the others don't).

---

### [Paperclip](https://paperclip.ing) · Solo or Team · General · MIT
**For:** Solo founders *and* teams running an autonomous "company of agents" across all business functions (dev, marketing, ops), not just code.
**UVP:** The only one that runs agents like a real company with **governance** — org chart with reporting lines, per-agent **budgets** with hard auto-pause caps, and board-style approval gates. "Manage business goals, not pull requests."

### [Multica](https://multica.ai) · Team · Engineer · Apache-2.0 (modified)
**For:** Engineering teams managing a mixed human + coding-agent workforce (built around multiple human collaborators).
**UVP:** A **Linear-style issue tracker** where agents are first-class assignees — they sit in the same dropdown as humans, open issues, comment, and run a full claim→complete lifecycle. Plus compounding reusable Skills shared team-wide.

### [Slock](https://slock.ai) · Solo or Team · General · closed
**For:** Solo agent-native builders and lean teams who want to talk to agents like teammates (free tier fits one person; scales to a team).
**UVP:** **Chat literally is the workspace** — Slack-style channels/DMs are the whole surface, and agents are persistent processes with their own memory that run on **your own hardware** via a local daemon.

### [Hivespace](https://hivespace.app) · Team · General · closed
**For:** Teams doing general knowledge work — invite teammates and agents into a shared space (a solo user can spin one up, but it's built for collaboration).
**UVP:** Each workspace is a **self-contained cloud computer with a shared file system** — every agent gets a private sandbox, the team shares editable files, and agents build live interactive web-app artifacts inside the workspace.

### [Vibe Kanban](https://github.com/BloopAI/vibe-kanban) · Solo or Team · Engineer · Apache-2.0 · *sunsetting*
**For:** Solo engineers *or* teams running multiple coding agents (Claude Code, Codex, Gemini, Copilot) in parallel — works privately or shared.
**UVP:** A **kanban board where each card spins up an isolated workspace** (own git branch + terminal + dev server) — plan, run agents in parallel, review diffs inline, and open PRs without leaving the UI. *(Project is sunsetting as of Apr 2026; now community-maintained.)*

### [First-Tree](https://first-tree.ai) · Team · Engineer · Apache-2.0
**For:** Engineering teams (1–100 agents) who want their GitHub flow to stay put while agents share team knowledge (solo doesn't need it — value comes from coordinating multiple people + agents).
**UVP:** A git-native shared **context layer, not an orchestrator** — lives in your repo as the team's "living memory" (decisions, design, ownership) so agents stop cold-starting, and auto-routes GitHub issues/PRs to the right agent.
